02 / GET STARTED

三步，把连接变简单。

初次使用？从这里开始。

01

选择适合的订阅

Clash Verge Rev、FlClash 或 Stash 选择 Clash 配置；v2rayN、v2rayNG 等支持节点链接的客户端选择全量或单协议订阅。

02

复制链接，导入客户端

点击“复制链接”，在客户端的订阅或配置页面新建远程订阅并粘贴。支持 Clash 的桌面客户端还可以尝试一键导入。

一个固定地址，持续使用。
03

更新节点，开启连接

保存后更新订阅，测试并选择可用节点，再开启连接。建议将客户端自动更新间隔设为 6 小时，跟随上游获取新节点。

03 / GOOD TO KNOW

你可能想知道。

关于订阅、更新和连接的一些说明。

阅读项目文档 ↗
订阅地址会过期吗？+

本站使用固定订阅地址，只要站点和对应源文件仍然提供服务，就无需重新获取链接。在客户端点击更新订阅即可获取新文件；本站边缘缓存最长 5 分钟，上游计划每 6 小时运行一次，实际以 GitHub Actions 为准。

“文件可获取”代表所有节点都能用吗？+

这个状态表示本站已成功读取并解析源文件。节点数量来自文件内容，更新时间来自 GitHub 附件；本站不进行实时连通性或速度测试。节点可用性会随时间与网络环境变化，请在客户端自行测试。

复制链接或一键导入没有成功？+

一键导入依赖客户端注册 clash:// 协议。若浏览器没有唤起应用，请手动复制链接，在客户端的订阅管理中添加。若剪贴板不可用，点击链接输入框可选中全文，再用系统复制功能。

可以直接用于 sing-box 或其他格式吗？+

这里分发的是仓库的原始产物：Clash YAML 和逐行节点 URI。没有提供 sing-box JSON，也不自动转换格式；只有明确支持对应订阅格式和协议的客户端才可直接导入。

订阅更新失败，或者节点连不上？+

先打开订阅文件，确认文件能读取。GitHub 正在替换附件时可能短暂失败，请稍后重试。能获取文件但节点无法连接时，更新订阅、切换节点并测试；免费共享节点的可用性与速度没有保证。
